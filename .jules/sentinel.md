## 2024-07-24 - Path Traversal Vulnerability in `channel_dir`
**Vulnerability:** A path traversal vulnerability existed in the `channel_dir` function where unsanitized user input (`channel` name) was concatenated directly with the `root` path. This could allow an attacker to escape the restricted chat root directory and read or write files anywhere on the filesystem if they passed paths like `../../etc`.
**Learning:** This vulnerability existed because there was no boundary check when forming paths from untrusted input, even when using Python's `pathlib.Path`.
**Prevention:** To prevent this in the future, always validate that constructed paths remain within the intended directory boundaries using `pathlib.Path.resolve().is_relative_to(root_path.resolve())` before accessing or creating files. Instead of calling process terminating functions like `sys.exit()` or `die()` in utility functions, raise standard exceptions like `ValueError` to prevent crashing importers or test runners.
