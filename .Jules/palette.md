## 2024-05-15 - Empty State for CLI Commands
**Learning:** Empty states in CLI apps often fail silently or with ambiguous statements (e.g., "no channels yet"), leaving users without actionable next steps.
**Action:** When printing an empty state summary in a CLI app, follow it up with a "Tip: run `command --args` to create one" to provide an immediate call-to-action, improving user onboarding.
